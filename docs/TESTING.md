# Estratégia de Testes

- Backend: Jest e Supertest para unidade e integração.
- Frontend: Vitest e React Testing Library.
- E2E: Playwright em desktop e tablet.
- Cobertura mínima: 80% statements/lines/functions e 75% branches.

Comandos: `pnpm test`, `pnpm test:coverage` e `pnpm test:e2e`.
Factories, fixtures e mocks ficam nos diretórios `test/` e `tests/` de cada app.
